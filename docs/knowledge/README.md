# Conocimiento institucional INTECA para agentes IA

Esta carpeta contiene la base de conocimiento que alimenta a los agentes del CRM.

## Archivos fuente

- `Base_Conocimiento_Agentes_INTECA.docx`: documento operativo para ventas, marketing, WhatsApp, publicidad, facturacion, contabilidad, compras, auditoria y direccion.
- `INTECA_Guia_Institucional_Cursos_y_Areas_Laborales.docx`: guia institucional de cursos, areas laborales, advertencias academicas, precios de referencia y datos institucionales.

## Archivos usados por el backend

- `base_conocimiento_agentes_inteca.md`
- `inteca_guia_institucional_cursos_y_areas_laborales.md`

Los agentes usan las versiones Markdown porque son mas rapidas y estables para cargar en los prompts. Si se actualiza un documento Word, tambien debe actualizarse su version Markdown.

## Reglas de uso

- Los agentes pueden parafrasear y conversar de forma fluida, natural y profesional.
- Los agentes no pueden inventar precios, fechas, certificaciones, avales, descuentos, pasantias, empleos garantizados ni resultados.
- Cuando una informacion no este confirmada, deben decirlo con claridad y escalar a Luis o a un asesor autorizado.
