SALES AI CRM 0.8.1 — CONFIGURACION HIBRIDA INTECA

Esta version puede lanzarse como CRM web y como aplicacion instalada en Windows o Mac. Ambas
presentaciones se conectan al mismo servicio HTTPS, por lo que comparten usuarios, contactos,
agentes y campañas. La carpeta desktop contiene los compiladores de instaladores. El archivo
compose.cloud.yml y la guia docs/DESPLIEGUE_HIBRIDO.md preparan el servicio central.

La instalacion local de Docker sigue disponible como contingencia, pero su base de datos es
independiente. No mezcle registros locales y centrales esperando sincronizacion automatica.

ACTUALIZAR UNA INSTALACION EXISTENTE
1. Abre Docker Desktop.
2. Extrae este ZIP en una carpeta temporal.
3. Ejecuta RESPALDAR.cmd en tu carpeta instalada.
4. Ejecuta DETENER.cmd.
5. Copia el contenido de SALES_AI_CRM sobre tu carpeta instalada en D:.
   Conserva el archivo .env original y la carpeta respaldos. No borres volúmenes Docker.
6. Ejecuta ACTUALIZAR.cmd y espera a que abra http://localhost:3000.
7. Pulsa Ctrl+F5 en el navegador.

INSTALACION NUEVA
1. Copia la carpeta SALES_AI_CRM al disco deseado.
2. Abre Docker Desktop y espera que esté listo.
3. Ejecuta INSTALAR.cmd.
4. Crea la empresa con el nombre exacto INTECA SRL.
5. Cierra e inicia nuevamente el CRM para que se cargue la configuración de INTECA.

La configuración se aplica sin borrar registros: licencia permanente, once agentes, curso
confirmado, campañas en borrador, embudo, seguimientos y política comercial. Tus contactos,
pagos, conversaciones y documentos existentes se conservan.

Para generar respuestas reales configura Gemini en Integraciones. WhatsApp, Facebook,
Instagram y correo requieren credenciales oficiales y, para uso externo, un servidor HTTPS.
No compartas contraseñas ni claves. Los anuncios permanecen como borradores: esta versión
no compra ni publica publicidad automáticamente. Revisa docs/CONFIGURACION_INTECA.md y
docs/CANALES_Y_PAGOS.md antes de habilitar respuestas automáticas.

ESTUDIO CREATIVO
El menú Estudio creativo INTECA genera vistas previas PNG para publicaciones cuadradas,
historias y anuncios horizontales usando siempre el logo y el icono oficiales. Noticias y
noticias y testimonios se guardan como borradores y deben enviarse a revisión. Solo el propietario
puede aprobarlos. Los testimonios requieren fuente real y permiso. Las campañas comerciales pueden
marcarse para publicación automática dentro del público y presupuesto autorizados, pero solo se
publicarán cuando la API oficial del proveedor esté conectada; cada publicación o fallo debe notificarte.
